How it works

One throwaway machine. Three moves.

An AI reads the message and plans like a candidate. Everything after that is observed behaviour and fixed rules.

  1. 01

    Paste

    Drop in the recruiter's message or the repo link. Vultr Serverless Inference reads the message for red flags, finds the repo and plans what a candidate would run.

    AI reads & plans
  2. 02

    Detonate

    A fresh Vultr VM boots for this repo alone. Fake AWS keys, SSH keys, wallets and .env files sit in a gVisor sandbox behind a fake internet. Burner runs it like you would: VS Code, npm install, npm start, the tests, then 45 days later.

    Fake secrets · Vultr Cloud Compute
  3. 03

    Read the evidence

    Fixed rules set the verdict; the AI only explains it. You see the exact bytes that left and where they went, with a report-it kit. Then the VM is destroyed and the evidence goes to Vultr Object Storage.

    Rule-based verdict
VM destroyed · nothing on your laptop

Why this exists

Platforms each solve a piece — open-source experiments are starting — nobody has put the whole puzzle together in a candidate's hands.
