How it works

Seven steps, one throwaway machine

An AI reads the message and plans like a candidate. Everything after that is observed behaviour and fixed rules.

  1. 1

    Read

    Vultr Serverless Inference reads the recruiter's message for red flags and finds the repo.

    AI
  2. 2

    Boot

    A fresh Vultr VM (or one pre-armed from the warm pool) starts, only for this repo.

    Vultr Cloud Compute
  3. 3

    Bait

    Fake AWS keys, SSH keys, wallets, browser passwords and .env files are planted in a gVisor sandbox.

    Fake secrets
  4. 4

    Run

    It acts like a candidate: opens the folder in VS Code, npm install, npm start, tests, then jumps the clock 45 days.

    Observed
  5. 5

    Catch

    A fake internet answers every connection and records what was sent, so stolen fake values show up byte for byte.

    Observed
  6. 6

    Judge

    Fixed rules decide the verdict. The AI only explains it, so it can't be talked out of one.

    Rule-based
  7. 7

    Destroy

    The VM is deleted with everything on it. The evidence bundle goes to Vultr Object Storage.

    Object Storage

Platforms each solve a piece of this — scanners, sandboxes, VMs, takedowns — and open-source experiments are starting. Nobody has put the whole puzzle together in a candidate's hands.
